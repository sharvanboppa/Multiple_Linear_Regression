# 📊 Multiple Linear Regression – Profit Prediction System

## 📌 Project Overview

The Multiple Linear Regression project is a Machine Learning-based application designed to predict business profits based on multiple input factors.

It uses **Multiple Linear Regression**, a supervised Machine Learning algorithm, to understand the relationship between different independent variables and a dependent variable (profit).

The project demonstrates how Machine Learning can be applied to analyze business-related data and estimate potential profits based on investment inputs.

## ✨ Features

- Predicts business profit using Multiple Linear Regression.
- Uses multiple input variables for accurate predictions.
- Performs data preprocessing and model training.
- Provides a simple and user-friendly interface.
- Generates profit predictions based on user inputs.
- Demonstrates practical implementation of regression algorithms.

## 🤖 Machine Learning Algorithm

This project uses **Multiple Linear Regression** to predict profit based on two or more independent variables.

### Model Development Steps

1. Import the required Python libraries.
2. Load the dataset.
3. Perform data exploration and preprocessing.
4. Identify independent and dependent variables.
5. Split the dataset into training and testing sets.
6. Train the Multiple Linear Regression model.
7. Evaluate the model performance.
8. Generate profit predictions using new input values.

## 📈 Prediction Process

The model predicts business profit based on multiple investment-related factors.

**Input:** Business investment details.

**Output:** Estimated business profit.

The model learns patterns from historical data and uses them to predict profit for new inputs.

## 🚀 Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/sharvanboppa/Multiple_Linear_Regression.git
```

### 2. Navigate to the Project Directory

```bash
cd Multiple_Linear_Regression
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000/
```

Enter the required investment details to get the predicted profit.
